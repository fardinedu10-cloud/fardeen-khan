# Fardhin Khan — Portfolio

A responsive software-engineer portfolio built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Files
- index.html — page structure
- style.css — responsive UI and design system
- script.js — personal information, projects, communication links, colors, and interactions

## Customize
Open `script.js` and edit these four objects:
1. `personalInfo`
2. `projects`
3. `communication`
4. `colors`

No framework is required.
